# 台股財報分析工具

自動化的台股四階段財務分析工具，包含 Piotroski F-Score、Altman Z-Score、杜邦分析、現金流量分析。

## 安裝

```bash
pip install -r requirements.txt
```

## 使用

### Web 介面（Streamlit）

```bash
streamlit run app.py
```

### 命令列介面

```bash
python cli.py 2330
python cli.py 2454
python cli.py 2317
```

## 功能

- **Piotroski F-Score**（滿分 9 分）：評估獲利能力、槓桿與流動性、營運效率
- **Altman Z-Score**（破產風險評估）：判斷安全/灰色/危險區域
- **杜邦分析**（ROE 因子分解）：淨利率 × 資產周轉率 × 權益乘數
- **現金流量分析**：營運現金流品質、自由現金流、現金流結構

## 資料來源

使用 FinMind API 取得真實財報數據：
- 資產負債表（年報）
- 綜合損益表（年報）
- 現金流量表（年報）
- 即時股價（用於計算市值）

## 分析架構

### 階段一：Piotroski F-Score
9 個指標逐一計算：
1. ROA > 0
2. 營運現金流 > 0
3. ROA 年增率 > 0
4. 營運現金流 > 淨利
5. 長期負債比率下降
6. 流動比率上升
7. 股份未稀釋
8. 毛利率上升
9. 資產周轉率上升

### 階段二：Altman Z-Score
Z = 1.2×A + 1.4×B + 3.3×C + 0.6×D + 1.0×E
- A = 營運資本/總資產
- B = 保留盈餘/總資產
- C = EBIT/總資產
- D = 市值/總負債
- E = 營收/總資產

判斷標準：
- Z > 2.99：安全區域
- 1.81 < Z < 2.99：灰色區域
- Z < 1.81：危險區域

### 階段三：杜邦分析
ROE = 淨利率 × 資產周轉率 × 權益乘數

### 階段四：現金流量分析
- 營運現金流品質（OCF / Net Income）
- 自由現金流（OCF - CapEx）
- 現金流結構分析

## 注意事項

- 資料來源為 FinMind API，僅支援台股
- 財報數據為年報，每年更新一次
- 市值計算使用最新股價 × 發行股數
- 所有計算過程都會顯示具體數字
